## vanin-downloader

this should work with all vanin ebooks. it has been tested on Genie Biologie 5 & 6 through ididdit

you need to install the extension, go to the webbook and press download images inside the extension

then copy the command it gives you and paste it in a terminal that has the project folder open. (append --ocr if you want a searchable, selectable pdf (takes longer))

### install

you need
- python

than run `pip install ocrmypdf pillow`

also install tesseract `sudo apt install tesseract`

not tested on windows but may work idk
